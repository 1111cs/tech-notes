## 推荐的笔记结构

每篇工具笔记可以按照以下顺序整理：

1. **解决什么问题**：先说明适用场景。
2. **最小可用步骤**：给出可直接复现的操作。
3. **常用参数与示例**：保留最实用的部分。
4. **易错点**：记录真实遇到过的问题和解法。
