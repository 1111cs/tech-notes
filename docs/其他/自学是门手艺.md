### 自学是门手艺

作者：李笑来（Li Xiaolai）

英文名：The Craft of Selfteaching

载体：GitHub 开源书籍 + Jupyter Notebook

项目地址：[GitHub 仓库](https://github.com/xiaolai/the-craft-of-selfteaching?utm_source=chatgpt.com)

我先说一个判断：这不是一本单纯教你 Python 的书，而是一本借助 Python 来训练自学能力的书。

它的核心主张是：

> 没有自学能力的人没有未来。

作者希望读者掌握的，不只是某项具体技能，而是一种能够不断迁移到其他领域的学习能力。

从项目结构来看，它采用 Jupyter Notebook 组织内容，把文字讲解、代码示例和练习放在一起。作者还提供了 Markdown 版本，方便不同阅读习惯的人使用。

值得注意的是，它不是简单地把传统书籍搬到 GitHub，而是把阅读、编程实践和读者参与校对结合起来。

 **另外，这本书的初稿完成于 2019 年，Python 环境、工具链和部分外部资源需要结合今天的情况更新。**
