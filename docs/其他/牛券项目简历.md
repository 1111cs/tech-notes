**项目名称：** 京东券平台
**项目时间：** 2025.12 – 2026.02
**技术栈：** Spring Boot 3 + MySQL + Redis（Lua / Bitmap / 布隆过滤器）+ Redisson + RocketMQ 5.x + ShardingSphere

**项目描述：** 面向平台商家及用户的优惠券业务系统，涵盖优惠券模板管理、批量发放及用户领取等核心业务，重点解决高并发领券、热点数据查询及大规模名单导入等场景下的性能与可靠性问题。

**核心职责：**

- **高并发领券：** 针对热门优惠券集中领取场景，采用 Redis Lua 实现库存校验、用户限领及库存预扣的原子化操作；通过 RocketMQ 异步完成数据库库存扣减及用户优惠券记录落库，并结合 AOP + Redis 实现消费幂等，降低数据库并发竞争。
- **优惠券批量发放：** 针对商家百万级 Excel 名单导入场景，采用 EasyExcel 流式解析降低内存开销；通过线程池异步处理发送数量统计，并利用 Redisson 延迟队列实现异常情况下的延迟检查与补偿。
- **优惠券查询：** 针对高频查询引发的缓存穿透与热点回源问题，构建 Redis 缓存治理方案，结合布隆过滤器、空值缓存、Redisson 分布式锁及双重检查机制，减少无效数据库查询并控制缓存重建并发。
